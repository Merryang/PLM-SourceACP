Supplementary Table S11. Paired few-shot MCC differences.

k is the number of support examples per class. Each row contains 20 paired draws from a seed-42 LOSO checkpoint. Differences are adapted minus no-adaptation query performance. Intervals use 10,000 repeat-level bootstrap draws. P values use two-sided Wilcoxon signed-rank tests with Holm correction across 12 MCC comparisons. Overlapping queries limit independent-replicate interpretation. Full AUC/AP/accuracy comparisons are in the accompanying CSV. Δ, difference. MCC, Matthews correlation coefficient. AUC, area under the receiver operating characteristic curve. AP, average precision. LOSO, leave-one-source-out. CI, confidence interval.
